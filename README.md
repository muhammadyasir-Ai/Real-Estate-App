# Real Estate Analytics & Recommendation App

A Python-based Real Estate Analytics application built with Streamlit to explore property market data, analyze housing trends, and support property-related decision-making.

The application provides interactive data visualizations, location-based analysis, property recommendations, and machine learning-based price prediction functionality.

## Key Features

- **Price Prediction:** Estimate property prices using machine learning.
- **Data Analysis:** Explore property trends through interactive charts and visualizations.
- **Property Recommendations:** Discover similar apartments based on available property data.
- **Location Analysis:** Explore property locations and location-based insights.
- **Interactive Dashboard:** Navigate real estate insights through a user-friendly Streamlit interface.

## Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Matplotlib
- Seaborn
- Scikit-learn
- Pickle

## Project Purpose

The goal of this project is to combine data analysis, visualization, and machine learning techniques to make real estate data easier to understand and explore.
